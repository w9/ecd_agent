# Agent instructions

## Uncommitted edits

- Before editing any file, check `git status`. If the working tree has uncommitted changes, refuse to edit and ask the user to commit first.

## Shorthands

- **AQ** = Ask multiple choice questions. Usually it's for clarification, but please infer the intention from the context. Always put a recommended answer first. Allow answering in the format `1a 2b 3d`.
